# АРЕАЛ-ПРОМ — корпоративный сайт

Статический корпоративный сайт строительной компании ООО «АРЕАЛ-ПРОМ» по техническому заданию: монтаж трубопроводов, технологических трубопроводов и инженерных сетей.

## Что внутри

- `index.html` — главная страница сайта.
- `privacy.html` — политика конфиденциальности.
- `404.html` — страница ошибки.
- `assets/css/styles.css` — стили сайта.
- `assets/js/main.js` — меню, загрузка контента, обработка формы.
- `content/services.json` — список услуг.
- `content/projects.json` — карточки объектов.
- `content/documents.json` — список документов.
- `docs/` — PDF-документы для скачивания.
- `robots.txt`, `sitemap.xml` — базовые SEO-файлы.
- `HOSTING.md` — подробная инструкция по публикации на хостинге.

## Локальный запуск

Сайт можно открыть напрямую через `index.html`, но для корректной загрузки JSON-файлов лучше запускать через локальный сервер.

В PowerShell из папки проекта:

```powershell
node server.js
```

Также можно использовать любой другой статический сервер или расширение Live Server в VS Code.

Адрес локального сайта:

```text
http://localhost:8080
```

## Что заменить перед публикацией

1. Контакты в `index.html`:
   - телефон;
   - email;
   - Telegram;
   - адрес офиса.
2. Домен в `index.html`, `robots.txt`, `sitemap.xml` вместо `https://example.com/`.
3. PDF-файлы в `docs/` на реальные документы компании.
4. Карточки объектов в `content/projects.json`.
5. При необходимости тексты услуг в `content/services.json`.
6. Подключить реальную обработку формы заявки: почтовый скрипт на хостинге, Formspree, Netlify Forms, backend или CMS.
7. Добавить счетчик Яндекс Метрики перед закрывающим тегом `</head>` в `index.html` и `privacy.html`.
